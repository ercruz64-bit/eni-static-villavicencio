# Landing Page ENI SENA

Prototipo responsive de la Escuela Nacional de Instructores "Rodolfo Martínez Tono".

## Tecnologías
- HTML5 semántico
- CSS3
- JavaScript ES6+
- Bootstrap 5.3.3
- Bootstrap Icons

## Estructura

```text
landing_eni_sena/
├── index.html
├── css/
│   └── styles.css
├── js/
│   └── script.js
└── README.md
```

## Ejecución

No requiere servidor para la versión demostrativa. Abra `index.html` en Chrome o Edge.

Para desarrollo puede usar VS Code + Live Server.

## Importante

Las tarjetas de capacitación son contenido demostrativo para el prototipo. Antes de publicar institucionalmente, deben conectarse con las convocatorias, cursos, fechas, cupos y enlaces oficiales vigentes de la ENI/SENA.

La identidad visual utiliza los colores institucionales como referencia, pero el logotipo mostrado en el prototipo es un marcador construido con CSS. Para publicación institucional, reemplácelo por el recurso gráfico oficial autorizado por el SENA.
